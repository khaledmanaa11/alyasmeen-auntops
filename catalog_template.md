## مثال — كيف يبدو المنتج في البوت بعد التعبئة

| ما كتبته | كيف يظهر للزبون |
|----------|-----------------|
| كريم اليدين - صغير / 25₪ | `1) كريم اليدين - صغير – 25₪` |
| كريم اليدين - كبير / 40₪ | `2) كريم اليدين - كبير – 40₪` |
| شمعة الياسمين / 50₪ | `3) شمعة الياسمين – 50₪` |

---

## بعد العودة — كيف تحوّل البيانات لـ catalog.json

```json
[
  {
    "name": "كريم اليدين - صغير",
    "category": "كريمات",
    "price": 25.0,
    "description": "كريم طبيعي مرطب لليدين بالزيوت العطرية.",
    "image": "hand_cream_small.jpg"
  },
  {
    "name": "كريم اليدين - كبير",
    "category": "كريمات",
    "price": 40.0,
    "description": "كريم طبيعي مرطب لليدين بالزيوت العطرية.",
    "image": "hand_cream_large.jpg"
  },
  {
    "name": "شمعة الياسمين",
    "category": "شموع",
    "price": 50.0,
    "description": "شمعة يدوية الصنع برائحة الياسمين.",
    "image": "candle_jasmine.jpg"
  }
]
```

> منتج بدون حجم؟ احذف حقل الحجم من الاسم فقط.
> الترتيب في الملف = الترتيب في قائمة البوت.
> منتج بدون صورة؟ احذف سطر `"image"` كاملاً أو اتركه فارغاً.
> **ملاحظة:** حقل الصورة محفوظ في الملف الآن لكن البوت لا يرسلها بعد — سنضيف هذه الميزة لاحقاً.
