## Research Findings To Carry Forward

- Keep the modular monolith; do not add microservices, Kubernetes, Redis, RabbitMQ, or Celery
  for the current scale.
- Deploy one FastAPI web role and one worker/scheduler role from the same immutable image.
- Persist and acknowledge Meta webhook events quickly; process slow work from a durable inbox.
- Record outbound work in a durable outbox with idempotency keys and bounded retries.
- Enforce agent authority in deterministic application policy and database constraints, not
  only in prompts.
- Use versioned Supabase migrations, pgTAP/database tests, least privilege, RLS where exposed,
  independent encrypted backups, and an exercised restore.
- Replace the permanent shared dashboard cookie with managed identity/MFA and server-side
  sessions; add CSRF and centralized authorization.
- Follow-ups and broadcasts must obey opt-in, approved-template, 24-hour-window, and opt-out
  rules.
- AI changes need representative bilingual/noisy/adversarial evals, deterministic fallbacks,
  cost/latency limits, and release thresholds.
- A staged pilot, restore drill, rollback drill, operator training, and incident response
  evidence are mandatory go-live gates.
