    Create a new migration to define PL/pgSQL functions for atomic job claiming using 'FOR UPDATE SKIP LOCKED'.

       - SELECTs 1 'pending' row from 'webhook_events'.
       - Updates status to 'processing' and sets 'processed_at' to now().
       - Returns the row.
    2. Define 'claim_outbox_job()':
       - SELECTs 1 'pending' row from 'outbox_jobs'.
       - Updates status to 'processing', increments 'attempts', and sets 'processed_at' to now().
       - Returns the row.
  </action>
