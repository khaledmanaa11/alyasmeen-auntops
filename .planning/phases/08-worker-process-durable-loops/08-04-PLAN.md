Purpose: Avoid duplicate scheduled jobs and ensure that the web server remains focused on handling HTTP requests while the worker handles all time-based and event-based tasks.
Output: A cleaner 'app/main.py' and a fully capable 'worker.py' managing all background operations.
</objective>
