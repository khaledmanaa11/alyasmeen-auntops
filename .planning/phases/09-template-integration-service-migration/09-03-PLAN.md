  <how-to-verify>
    1. Ensure `USE_MOCK_WHATSAPP=0` and real `WA_META_*` credentials are set in `.env`.
    2. Manually insert a test template job into the outbox:
       ```sql
       INSERT INTO outbox_jobs (transport, recipient, payload, status)
       VALUES ('whatsapp_meta', 'REAL_PHONE_NUMBER', '{"type": "template", "template_name": "hello_world", "language_code": "en_US"}', 'pending');
       ```
       (Note: `hello_world` is a default Meta template available in all accounts).
    3. Run the worker: `python worker.py --test-outbox`.
    4. Confirm the message arrives on the real phone number.
  </how-to-verify>
