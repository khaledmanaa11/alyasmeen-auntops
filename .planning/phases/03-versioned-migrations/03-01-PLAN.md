  <files>supabase/config.toml</files>

    2. Run `npx supabase link --project-ref ppwcfmuetgczclmnzvqr`.

<task type="auto">
  <name>Task 2: Baseline the Remote Schema</name>
  <files>supabase/migrations/*_baseline.sql</files>
  <action>
    1. Generate a timestamp (e.g., $(date +%Y%m%d%H%M%S)).
    2. Run the baseline dump command: `npx supabase db dump --linked -f supabase/migrations/${TIMESTAMP}_baseline.sql`.
    3. Edit the generated SQL file:
       - Keep only the `public` schema definitions (tables: products, customers, orders, order_lines, sessions, chat_history, follow_ups, retry_queue, monthly_snapshots).
       - Remove any Supabase-managed internal schemas like `auth`, `storage`, `vault`, `realtime`, etc., if they were included.
       - Ensure all indexes and constraints for these tables are retained.
  </action>
  <verify>
    <automated>ls supabase/migrations/*_baseline.sql && grep "CREATE TABLE public.orders" supabase/migrations/*_baseline.sql</automated>
  </verify>
  <done>Baseline migration file created and cleaned of internal schemas.</done>
</task>

<task type="auto">
  <name>Task 3: Repair Migration Status and Deprecate Legacy Schema</name>
  <files>app/db/schema.sql, legacy/schema.sql</files>
  <action>
    1. Extract the timestamp from the filename created in Task 2.
    2. Run `npx supabase migration repair --status applied ${TIMESTAMP}` to tell Supabase this migration is already in place.
    3. Run `npx supabase migration list` and verify the baseline is marked as 'applied'.
    4. Create the `legacy/` directory if it doesn't exist.
    5. Move `app/db/schema.sql` to `legacy/schema.sql`.
    6. (Optional) Create a new `app/db/schema.sql` with a "DEPRECATED" warning or just delete it if the codebase no longer references it directly for setup. Per instructions: move it or update with DEPRECATED header. Let's move it.
  </action>
  <verify>
    <automated>npx supabase migration list | grep "applied" && test -f legacy/schema.sql</automated>
  </verify>
  <done>Live database synced with migration history and legacy file moved.</done>
</task>
