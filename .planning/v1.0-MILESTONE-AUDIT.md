# Milestone Audit: M1 — Supabase → prod (v1.0)

**Audit Date:** 2026-06-15
**Status:** PASSED
**Coverage:** 13/13 Requirements Met

## Overview
This audit verifies that Milestone M1 has achieved its core value: making the Supabase data foundation production-ready. The "smoke-thread-first" approach successfully de-risked the Meta-to-Supabase path before the foundation was hardened.

## Requirements Coverage

### 1. Spine (smoke-thread)
- **SPINE-01 (Parsed Webhook)**: Verified. Minimal parser handles nested Meta envelope.
- **SPINE-02 (Live Order)**: Verified. Real orders write to Supabase and notify the aunt.

### 2. Schema Integrity
- **SCH-01 (monthly_snapshots)**: Verified. Table exists in migration and live DB.
- **SCH-02 (Single Source of Truth)**: Verified. `schema.sql` matches live Supabase.
- **SCH-03 (Startup Check)**: Verified. `validate_schema()` runs in FastAPI lifespan.

### 3. Migrations
- **MIG-01 (Versioned Migrations)**: Verified. Sequential SQL migrations established in `supabase/migrations/`.
- **MIG-02 (Fresh Project Reproduction)**: Verified. Migrations baseline the verified schema.

### 4. Database Security Surface
- **SEC-01 (Least-Privilege Key)**: Verified. App uses `service_role` explicitly; documented in `.env.example`.
- **SEC-02 (Constrained RPC)**: Verified. `run_query`/`run_exec` restricted to `service_role`; `anon` access revoked.

### 5. Data-Loss Insurance
- **BAK-01 (Nightly Export)**: Verified. `app/services/backup.py` automated via APScheduler.
- **BAK-02 (Restore Runbook)**: Verified. `docs/RESTORE.md` created with tested instructions.

### 6. Bounded Growth
- **RET-01 (chat_history pruning)**: Verified. Daily job keeps 30 days of context.
- **RET-02 (retry_queue pruning)**: Verified. Daily job prunes resolved retries > 30 days.

## Cross-Phase Integration
- **FastAPI Lifespan**: Successfully integrates schema validation, backup scheduler, and retention scheduler.
- **Database Adapter**: The single `database.py` adapter now serves as the secure, resilient gateway for all services.
- **Configuration**: `config/setup.json` correctly manages intervals and windows for all new background jobs.

## Accumulated Tech Debt & Gaps
- **Backup Location**: Backups are stored locally on the server. Moving to off-site storage (S3) is recommended for M2/M3.
- **Webhook Hardening**: Signature verification and full envelope parsing are deferred to M2.

## Conclusion
Milestone M1 is complete. The data layer is stable, versioned, secured, and protected against data loss. Proceed to Milestone M2.
