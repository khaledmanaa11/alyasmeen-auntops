{# Shared dashboard nav partial — the single copy of the nav block, included by every page template (orders, dashboard, products, broadcast, alerts). Self-highlights the active tab from request.url.path instead of taking a per-template `active` variable. Starlette's Jinja2Templates always puts `request` in the template context (every page renders through templates.TemplateResponse(request, ...)), and a Jinja2 {% include %} inherits the parent's context — so this partial can read the current path directly and every call site stays a bare include with nothing to pass. That is what makes the extraction pay off: adding a new nav tab means editing this ONE file, never the five page templates. Class strings below match the pre-extraction markup byte-for-byte per link (active: "nav-active ... font-bold shadow-sm", inactive: "nav-link ... font-medium") so the rendered nav is visually identical to before the extraction. #} {% set _p = request.url.path %}
